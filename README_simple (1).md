# Dashboard Kaise Chalayein

## Step 1: Python download karo
👉 python.org website par jao aur Python download karo.
Install karte waqt neeche wala box zaroor tick karna: **"Add python.exe to PATH"**

## Step 2: Do cheezein install karo
Apne computer mein "Command Prompt" ya "Terminal" kholo aur ye line likh kar Enter dabao:

```
pip install pandas matplotlib
```

## Step 3: Files ek jagah rakho
Ye dono files ek hi folder mein rakho:
- `attractive_dashboard.py`
- `sales_data.csv`

## Step 4: Us folder mein terminal kholo
Folder ke andar khali jagah par **Shift dabakar Right-click** karo, phir "Open PowerShell here" par click karo.

## Step 5: Chalao
Terminal mein ye likho:

```
python attractive_dashboard.py
```

Agar ye kaam na kare to ye try karo:

```
python3 attractive_dashboard.py
```

## Step 6: Result dekho
Usi folder mein ek **naya image file** ban jayegi naam ka `attractive_dashboard.png` — usko double click karke kholo. Dashboard dikh jayega!

---

## Kuch problem aaye to

**"pandas nahi mila" jaisa error aaye**
→ Step 2 wapas karo: `pip install pandas matplotlib`

**"python nahi chal raha" jaisa error aaye**
→ Python phir se install karo, "Add to PATH" wala box zaroor tick karo

**"file nahi mili" jaisa error aaye**
→ Check karo dono files (.py aur .csv) same folder mein hain ya nahi
